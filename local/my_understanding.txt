* **Scope:** only `CA`, `OR`, `WA`
* **Grain:** one row per university chapter
* **Business key:** `chapter_id`
* **Bronze:** raw/near-raw API payload + ingestion metadata
* **Silver:** typed, flattened, deduplicated, DQ applied
* **Gold:** consumer-facing data product; **no quarantined records**
* **DQ-Q1:** invalid/missing coordinates → quarantine
* **DQ-W1:** missing/blank/`UNKNOWN` city → warning but publish

  * `rows_ok`
* `OR`/`WA` being empty is **valid**

* `CA = 0` unexpectedly → failure/alert
* Gold should be **idempotent-ish**
* No Terraform/Bicep, CI/CD, streaming, scheduler, etc.
* Spark/PySpark should be clearly visible
* README must allow a reviewer to reproduce the solution
* Fixture must demonstrate **both quarantine and warning**
* Data Product Contract is mandatory
